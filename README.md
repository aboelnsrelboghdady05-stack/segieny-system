# شركة مقاولات السجيني - المنظومة الرقمية لإدارة المشاريع والمصروفات

منظومة سحابية وإدارية متكاملة مصممة خصيصاً لشركات المقاولات، لتمكين إدارة الشركة والمهندسين والمشرفين من متابعة كافة مواقع العمل، أوامر الشغل والتاسكات الميدانية، نسب الإنجاز، والمصروفات والفواتير مع إرفاق المستندات وسندات القبض.

---

## 🌟 الميزات الرئيسية للمنظومة

### 1. إدارة المشاريع ونسب الإنجاز (Projects Management)
- متابعة كاملة لكل مشروع: اسم المشروع، المالك/العميل، الموقع الجغرافي، الميزانية وقيمة العقد، وتواريخ البدء والانتهاء.
- مؤشر بصري وتفاعلي لنسبة الإنجاز الفعلي لكل مشروع.
- مقارنة مالية حية بين قيمة العقد وإجمالي المنصرف الفعلي والمتبقي من الميزانية.
- صفحة تفصيلية متكاملة لكل مشروع تضم كافة متعلقاته (مصاريف وفواتير، مهام، مقاولو باطن، مخططات).

### 2. إدارة المهام والتاسكات الميدانية (Task Management & Kanban)
- إسناد المهام للمهندسين والمشرفين مع تحديد الأولوية (عاجل وطارئ، مرتفع، متوسط، منخفض).
- لوحة مهام مرئية (Kanban Board) مقسمة إلى: (قيد الانتظار، جاري التنفيذ بالموقع، مكتملة ومستلمة من الاستشاري).
- تحديث فوري لنسبة إنجاز كل مهمة مع شريط تقدم.
- إمكانية التصفية بالمشروع، بالموظف، أو بالحالة.

### 3. المصاريف والفواتير وأرشفة الإيصالات (Expenses & Invoices)
- تسجيل كافة بنود الإنفاق:
  - مواد بناء (حديد، أسمنت، خرسانة، طوب، رمل...).
  - عمالة ومقاولين باطن (يوميات ومستخلصات).
  - معدات وآليات (أوناش، حفارات، سقالات).
  - محروقات ونقل وتشوينات.
  - تراخيص وتأمينات وهندسي.
  - نثريات وإداريات وضيافة.
- **إرفاق صور الفواتير وسندات القبض والإيصالات** بصيغ الصور أو ملفات PDF مع إمكانية المعاينة بضغطة زر داخل التطبيق (Lightbox Preview).
- تتبع طرق الدفع (تحويل بنكي / سريع "سداد"، بطاقات مدى، شيكات مصرفية، نقدي / عهدة).
- **تصدير شيت إكسيل (Excel)** كامل لكافة المصروفات بضغطة زر واحدة.

### 4. حسابات مقاولي الباطن والعمالة (Subcontractors & Labor)
- سجل لجميع المقاولين (حدادة، نجارة، سباكة، كهرباء، محارة، هياكل ستيل).
- حساب إجمالي قيمة الاتفاق، المسدد، والمتبقي.
- صرف المستخلصات والدفعات مع إرفاق سند الصرف وترحيلها تلقائياً لمصاريف المشروع.

### 5. أرشيف المخططات الهندسية والمستندات (Blueprints & Documents)
- أرشفة الرسومات المعمارية والإنشائية ورسومات الـ MEP وتراخيص البناء وتقارير التربة.
- إمكانية استعراض المخططات وتحميلها مباشرة من الموقع.

### 6. التقارير والطباعة (Reports & Print)
- تقرير مالي وتنفيذي مفصل لكل مشروع مجهز للطباعة الفورية على ورق A4 بنقرة زر.

## 🚀 كيفية تشغيل المنظومة

### الطريقة الأولى (الأسهل بنقرة زر):
من المجلد، قم بالضغط المزدوج على ملف:
```bash
./start.sh
```
أو افتح مبنى الأوامر (Terminal) واكتب:
```bash
bash start.sh
```
سيقوم السكريبت بتشغيل المنظومة وفتح المتصفح تلقائياً على الرابط:
👉 **`http://localhost:5001`**

### الطريقة اليدوية:
```bash
# 1. تفعيل بيئة العمل
source venv/bin/activate

# 2. تشغيل السيرفر
python3 app.py
```
ثم افتح المتصفح على: `http://localhost:5001`
